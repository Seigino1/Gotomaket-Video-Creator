# 多语言、旁白、音乐与动作音效

中文与英文是已验证起点，计划可用任意语言标签。每个语言同时处理脚本、上屏文案、UI、旁白、字幕与 CTA，不能只换旁白。不翻译品牌/代码术语的名单写入方向文件。

## 免额外鉴权优先

优先用户已给素材和宿主订阅内当前可用的声音工具；其次既有本地/系统 TTS。macOS 可列出 `say -v '?'` 中可用声音，分别选支持目标语言的已安装 voice，用 `say -v <voice> -f <文案文件> -o <音频文件>`，再由 FFmpeg 转换。Linux/Windows 使用当前已安装的系统语音或离线工具；不强制安装需 API Key 的配音服务。

没有对应声音时可先交付带字幕预览，明确缺少旁白；用户要求带配音的正式片必须补齐后才算完成。用户授权静音时记录 silentReason。声音工具未被宿主订阅覆盖时，不能声称免费。

旁白文字保存到 `narration/<语言>.txt`；由选定工具执行生成，实测每句长度和停顿。字幕帧窗写回 plan，`export_captions.py` 导出 SRT/VTT。已有音频但无逐句时间时，使用宿主已有转录工具或听录标注，不把按字符均分称作精准时间。

## 混音

每语言先形成一个完整本地 master（旁白/音乐/音效）保存 `public/audio/<语言>.wav`，写入 plan.audio。旁白清晰优先，音效对齐动作，音乐在旁白/反馈时让位；片尾音乐应按镜头收束。clip 的原生声音默认静音，只有明确设计时保留。

归藏原始固定音效在 `vendor/guizang/assets/audio/sfx/`，先看 SOURCE 与 manifest 再按需复制；测落点直接调用 `sfx_landmarks.py <文件>`。混音参考见归藏适配。代码合成音乐可研究上游例子的技法，但本包不含随机噪声生成脚本；配乐按新片节奏制作，不把示例曲作为固定模板。

为了对应旁白时长，记录 ffprobe 时长、实际语句结束时间、字幕窗口、镜头可用时间。长于窗口先精简译文或增加停留，不默认加速导致听不清。

## 分语言验收

至少看长标题、最密集 UI、字幕、CTA 与末帧；英文检查意外中文，其他语言检查字形覆盖。字体进入本地工程，记录许可。音频检测只证明音轨和长度，需实际试听语言、口音、停顿、错读、音效与音乐平衡。
