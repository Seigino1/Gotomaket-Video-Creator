# 品牌与镜头模板

模板复用结构与参数，不把某产品 logo、案例、配色和旧动作强加给下一个产品。

| 模板 | 主角与结果 | 建议动作 |
|---|---|---|
| 品牌开场 | 产品与一句定位 | 首帧完整，核心符号引出工作区 |
| 连续流程 | 输入、处理、输出 | 同一对象沿流程前进，追踪关注位置 |
| UI 特写 | 操作目标和真实反馈 | 点击/输入/展开/滚动，坐标取实际布局 |
| 数据图解 | 证据或明确模拟数据 | 数值/关系准确，动画展示过程 |
| 片尾 | 品牌与一个行动 | 留阅读时间，持续运动按本片意图选择 |

模式：`repo` 沿用品牌；`hybrid` 保留 UI 优化外层；`custom` 从指定参考自建。默认从产品推导，不用第三方默认品牌作为通用风格。

1080p 起点：界面正文尽量 ≥22px，上屏正文约 34–48px、标题约 68–96px、安全边距约 80px；按平台实测，竖屏重新排版。字体覆盖目标语言并保留来源许可。

`DIRECTION.md` 写产品气质、参考拆解、方向与理由、色板/字体/安全区、场景结构、动效语法、声音和镜头表；token 存 `plan.theme`。检查英文长文、中文换行与裁切。
